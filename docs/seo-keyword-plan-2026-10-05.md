Do not publish any figure in these posts that is not on an official page. If it cannot be
sourced, leave it out.

## 4. On-page rules for every target page

- Title: primary keyword + "2026" + the three proof words people search ("Cost, Visa &
  Scholarships"). Keep under about 60 characters.
- First screen: a quick-answer box with the figures students ask for and a "last updated" line.
- H2s phrased as the questions people type (AEO). FAQ answers 40-60 words, start with the answer.
- Official sources listed on the page (done on UK, USA, Canada, Australia).
- Each country page links to its cluster posts and back. Each cluster post links to the
  country page in the first paragraph.
- Never state a rule without its date.

## 5. Measure

Weekly: impressions and average position for the primary keyword of each cluster, clicks on
COMPEX, and whether ChatGPT, Perplexity and Google AI cite admizzeducation.com for 20 fixed
questions (for example "how much money do I need for a UK student visa").
